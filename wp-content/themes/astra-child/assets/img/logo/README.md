# YAZAN logo

Drop the brand logo file(s) here, then I'll trim the whitespace, generate the right sizes, and
wire it into the header.

Preferred: a **transparent PNG** (or SVG) of the gold YAZAN mark. Name it `yazan-logo.png`
(or `.svg`). A maroon-background version can go here too as `yazan-logo-maroon.png` if you want a
variant for the maroon theme.

Once the file is here, the finish step produces:
- `yazan-logo.png`      — trimmed, ~360px wide (header)
- `yazan-logo@2x.png`   — retina (~720px)
- `yazan-favicon.png`   — square (512×512) for the site icon

and enables the gold logo in the header (disabling the monochrome-darken filter so the gold shows).
